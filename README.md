# 特效模板库

Windows 本地特效模板库。主要流程是配置素材目录和 PostgreSQL、拖入或选择工程、确认归档内容、发布、按标签查询，以及导出模板包。

## Windows 安装包

使用 Inno Setup 6 编译。开发环境安装依赖后执行 `npm.cmd run release:win`，安装程序输出到 `release/`。可通过 `VFX_ISCC` 指定自定义的 Inno Setup 编译器路径。安装版沿用 Windows 用户的 `%APPDATA%\vfx-template-library` 配置，数据库连接和素材库位置在应用里维护。

## 启动开发版

使用 Node.js 24 和 PostgreSQL 18。Windows 上运行以下命令。

```powershell
npm.cmd ci
npm.cmd run dev
```

首次配置时，建议连接本机 PostgreSQL `127.0.0.1:5432`，数据库名可用 `vfx_templates_dev`。如果库还未创建，选择空的素材目录并使用具有建库权限的账号，应用会自动创建 UTF-8 专用库。也可连接由管理员预先创建、并已授权建表的独立数据库。界面可以设置备份目录、执行时间和保留份数。手动备份及定时备份产物为 PostgreSQL 自定义格式加 SHA-256 校验文件。默认查找 PostgreSQL 18 的标准安装目录，也可使用 `VFX_PG_BIN` 指定工具目录。

通过左侧「运行日志」打开 JSONL 文件所在目录。每条记录含时间、模块与事件名。导入及备份任务含任务 ID、处理阶段、数量、耗时和错误，涉及单个文件失败时保留相对路径。设置请求的数据库密码不写入日志。

导入时可在窗口底部确认发布。归档进度显示当前文件、累计字节量和处理阶段。文件先复制到素材库的 `staging/`，校验通过后再提交数据库。提交失败会清理该次归档生成的文件。如果进程突然退出或提交结果暂时无法确认，下次启动会核对数据库并处理残留。已发布模板可以在详情修改标签，或移入回收站后恢复。

## 当前开发范围

归档和后台任务由当前用户启动的 Electron 进程执行。Windows 可用托盘时，关闭窗口会最小化到托盘，定时备份继续运行。通过托盘退出后停止后台任务，重新打开应用会补做最近一次已到期的计划。独立 Windows 服务、操作系统级归档目录写保护、DCC 依赖扫描、整库迁移恢复、媒体转码和 AI 建议属于后续阶段。开发版仅支持当前播放器可解码的 MOV。扫描暂以当前目录为边界，从子目录内拖入单个文件时可改为选择项目根目录。

可以把多个文件夹和文件拖到同一次导入预检，也可以用预检中的「添加目录」「添加文件」分批加入。选择的目录会递归扫描。来源分散在不同目录时，单独选中的文件按文件收录。预检列出各来源和归档路径，归档时会检查同名文件冲突。

导入预检将带帧号的渲染和缓存按文件夹合并，例如 `houdini/render/trail/`。`geo/` 内的缓存以及 `.geo`、`.bgeo`、`.sc` 文件默认不勾选。手动勾选的 `.sc` 缓存归档到与 Houdini 工程同级的 `geo/`。其他标准目录为 `abc/`、`tex/`、`hdr/`、`hda/`、`render/`。勾选的自定义目录按原项目相对路径归档，`.sc` 缓存按上述规则收录。

识别时递归检查选定目录下的文件。HIP、NK、缓存、MOV 等可位于任意层级，图像序列根据实际文件名和帧号分组。标准目录名可辅助区分贴图与渲染。模板详情里的「打开模板目录」会直接在资源管理器打开归档后的 `project/` 目录。

精简模板包带工程和主预览，完整模板包附带本次归档的依赖文件。两者包含清单及归档后的相对路径。源路径与归档路径不同时，清单记录路径对应关系。工程里依赖原路径的引用需要在 Houdini 或 Nuke 中重连。数据库备份与模板包的用途及后续设计见 [设计文档](docs/特效模板库设计.md)。

## FX Agent 只读查询

首次接入时，打开 [FX Agent 仓库](https://github.com/Zylvia-lin/fx-agent)，按仓库 README 的「快速开始 → 安装与连接」完成安装并连接 Codex。本节的联动查询需要 FX Agent 提供 `fx_search_published_templates` 工具。

启动更新后的桌面端，连接素材库后保持运行，可以最小化到托盘。重新连接 FX Agent 后，使用 `fx_search_published_templates` 按模板名称或标签搜索已发布模板。每次最多返回 25 条，有后续结果时会提供 `nextOffset`。原有的 `fx_search_templates` 继续查询 FX Agent 的模板研究库。

FX Agent 在搜索前检查本机接口和数据库连通性。本机无可用模板库时，工具以 `available: false` 标记该来源，并略过搜索。若使用自定义 `VFX_USER_DATA`，桌面端和 FX Agent 进程需要使用同一配置目录。

## 验证

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

可选 PostgreSQL 集成测试使用 `VFX_TEST_PG_PORT` 开启。请使用专用临时实例和有建库权限的 `vfx_test` 测试账号。每次运行创建并清理一个独立的随机命名测试库。
